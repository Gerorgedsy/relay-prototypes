# Relay Prototypes

Three clickable prototypes for Relay, a worry tracker for bedside nurses (Team #3).

- `index.html`: start page with links to all three
- `simple.html`: Prototype 1, Relay Simple
- `team.html`: Prototype 2, Relay Team
- `together.html`: Prototype 3, Relay Together

Each page is a single self-contained HTML file. All patients and names are made up.

## Publish with GitHub Pages

1. Create a new public repository and upload all files in this folder.
2. Go to Settings → Pages.
3. Under "Build and deployment", set Source to "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. After a minute or two, the site is live at `https://<username>.github.io/<repo-name>/`.
